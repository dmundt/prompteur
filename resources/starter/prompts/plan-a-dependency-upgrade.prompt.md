Plan this dependency upgrade:

{{text}}

- Inspect current manifests, lockfiles, runtime constraints, and direct consumers.
- Verify target compatibility and breaking changes from available authoritative sources.
- List ordered changes, focused regression checks, and rollback steps.
- Separate required adaptations from optional modernization; mark unverified claims.
- Plan only; do not install packages, change versions, or publish.
