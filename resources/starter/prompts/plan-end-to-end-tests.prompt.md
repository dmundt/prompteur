Plan end-to-end tests for these workflows:

{{text}}

- Identify critical journeys, user roles, preconditions, and observable completion criteria.
- Prioritize success, cancellation, error recovery, and access restrictions by risk.
- Specify isolated fixtures, deterministic setup/cleanup, and appropriate native or browser tooling.
- Separate automated checks from manual accessibility/platform checks.
- State coverage gaps and required approvals. Plan only; do not execute external operations.
