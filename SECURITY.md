# Security Policy

Prompteur stores prompt libraries locally. It makes no direct model/provider calls and collects no telemetry. The approved Copilot Language Model Tool is read-only; VS Code requests confirmation before sharing prompt content and requested context with the configured model.

Do not report vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/dmundt/prompteur/security/advisories/new) to report security concerns. Include affected versions, impact, and concise reproduction steps; do not attach private prompts, credentials, or workspace content.

Security updates are handled through GitHub Dependabot alerts and update pull requests.
