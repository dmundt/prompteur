# Icons

Use VS Code Codicons: `person` (User), `root-folder` (Workspace), `warning` (invalid frontmatter), and action icons. Category/prompt rows use text only. Custom assets:

- [Activity Bar icon](../resources/activity/prompts.svg): White tent outline, flag, open entrance, 0.8-unit square strokes, miter joins, 45-degree roof, 16-unit grid. No cat.
- [Marketplace icon](../resources/icon.png): 128×128 red, yellow, and blue circus tent with a seated white cat, curled tail, and abstract navy eyes and mouth in the dark entrance; minimal padding and no frame.

- Activity Bar SVG renders as a theme-colored mask, not multicolor. Accessible label: **Prompteur**.
